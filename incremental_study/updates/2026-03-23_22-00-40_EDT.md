- [models/__init__.py](/Users/chris/Developer/school/csc490-v2/incremental_study/models/__init__.py)

The standalone harness now resolves its dependencies internally:
- [model_loader.py](/Users/chris/Developer/school/csc490-v2/incremental_study/model_loader.py) now imports architectures from the local `incremental_study.models` package
- [verifier_adapter.py](/Users/chris/Developer/school/csc490-v2/incremental_study/verifier_adapter.py) now imports `auto_LiRPA` from the local vendor directory

## Why This Refactor Was Done

This makes the new study harness more self-contained and avoids tight coupling to:
- the external `alpha-beta-CROWN` checkout layout
- the external `IVAN` checkout layout

That is better for:
- reproducibility
- future experimentation
- cleaner repository organization
- running the study without depending on the legacy experiment pipelines

## What Did Not Change

The conceptual scope is unchanged:
- still independent from-scratch verification for `M` and `M'`
- still no proof transfer
- still no template store
- still no reused proof trees or cross-run cache
- still root-stage `auto_LiRPA` artifact logging only in V1

## Current Dependency Shape

The standalone study now has these local dependencies:
- vendored `auto_LiRPA` backend in `incremental_study/vendor/auto_LiRPA`
- vendored model definitions in `incremental_study/models`

It still expects runtime packages such as:
- `torch`
- `torchvision`
- `numpy`
- optionally `onnx` and `onnx2pytorch` for `.onnx` model loading
